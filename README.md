# E-Commerce UMKM Morry48

Proyek ini merupakan tugas mata kuliah **Rekayasa E-Bisnis** berupa perancangan dan pembuatan sistem **E-Commerce untuk UMKM Morry48**, yang bergerak di bidang penjualan gantungan kunci custom.

## 📌 Deskripsi Proyek
Sistem E-Commerce Morry48 dirancang untuk membantu UMKM dalam:
- Menampilkan katalog produk secara online
- Mengelola data produk dan pesanan
- Mempermudah proses pemesanan dan transaksi
- Meningkatkan jangkauan pemasaran secara digital

Aplikasi ini berbasis web dan dibangun menggunakan PHP dan MySQL.

## 🛠️ Tools & Teknologi
- PHP
- MySQL / MariaDB
- XAMPP
- Visual Studio Code
- HTML, CSS, JavaScript

## 📂 Isi Repository
- `morry48.zip` : Source code aplikasi web E-Commerce
- `db_morry48.sql` : Database MySQL untuk sistem Morry48
- `README.md` : Dokumentasi proyek

## ⚙️ Cara Menjalankan Aplikasi
1. Install XAMPP
2. Extract file `morry48.zip`
3. Pindahkan folder ke direktori `htdocs`
4. Import database `db_morry48.sql` melalui phpMyAdmin
5. Jalankan aplikasi melalui browser
